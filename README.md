# Hi 👋, I'm Benjamin Guiganton

### R&D & Product Engineer · AI · Automation · Full-Stack Systems

I design and build practical software solutions at the intersection of **product conception, artificial intelligence, automation, and full-stack development**.

My work usually starts with a real operational problem: understanding the workflow, designing the solution, building a prototype, validating it with users, and working toward a production-ready implementation.

I have a strong web development background with **Laravel, PHP, JavaScript, Livewire, React, Python, Docker, and SQL**, but my current focus goes beyond traditional web development.

## 🧠 What I work on

### AI & R&D

I experiment with AI systems and turn promising ideas into practical prototypes.

My work includes:

- AI-assisted internal tools
- Multimodal and visual product recognition
- CLIP-based image similarity search and vector databases
- LLM integrations and AI agents
- Local AI deployment and inference experiments
- Computer vision prototypes with Python
- Evaluation of new AI models, tools, and architectures

### ⚙️ Automation

I build automation systems that connect existing business processes, databases, APIs, and internal applications.

Typical projects include:

- n8n workflows
- Python automation scripts
- Database-driven automation
- API integrations
- Data collection and transformation pipelines
- Internal productivity tools
- Replacing repetitive manual operations with reliable automated workflows

The objective is not automation for its own sake: it is reducing operational friction and giving teams better tools.

### 🧩 Product Conception

A growing part of my work is focused on defining **what should be built before deciding how to build it**.

I work on:

- Product and feature conception
- Internal tool specifications
- Workflow analysis
- Mockups and MVPs
- Technical feasibility studies
- Business rules and system behavior
- Translating operational requirements into features developers can implement

This allows me to bridge the gap between business teams, operations, R&D, and software development.

## 🔬 Areas I'm currently exploring

I'm particularly interested in technologies that connect software with the physical world:

- Warehouse automation
- Robotics
- Computer vision
- AI-assisted operations
- Multimodal AI
- Local AI infrastructure
- Human + AI workflows
- Autonomous and semi-autonomous agents

I believe the most interesting systems won't simply be "AI applications" — they will combine **software, data, AI, automation, and physical operations**.

## 🚀 How I approach projects

I like working from problem to solution rather than from technology to technology.

**Problem → Research → Prototype → Validation → Specification → Implementation → Automation**

Sometimes the right solution is a Laravel application.

Sometimes it is a Python script.

Sometimes it is an n8n workflow.

Sometimes it is an AI model connected directly to existing data.

The technology is secondary to solving the problem effectively.
